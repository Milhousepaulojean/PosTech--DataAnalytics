# PosTech - Data Analytics

Repositório dedicado aos estudos e projetos desenvolvidos durante a pós-graduação em Data Analytics.

## Sobre

Este repositório contém atividades, exercícios e projetos práticos abordando temas como análise de dados, visualização, machine learning e estatística.

## Tecnologias Utilizadas

- Python
- SQL
- Pandas, NumPy, Matplotlib, Seaborn
- Scikit-learn
