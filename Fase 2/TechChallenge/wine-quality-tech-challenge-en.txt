Case: Classifying Wine Quality with Machine Learning

The wine industry has significant economic and cultural importance in several countries. Traditionally, wine quality is assessed by experts through sensory analysis, considering aspects such as aroma, flavor, acidity, and balance. However, this process can be subjective and time-consuming, and it depends on the evaluators' experience.

With the advancement of data science and machine learning techniques, it has become possible to use physicochemical data collected during wine production to help predict the final quality of the product. Predictive models can therefore support winemakers and producers in decision-making, enabling adjustments to the production process and contributing to quality standardization.

This challenge uses the Wine Quality Dataset, which is publicly available on Kaggle and contains physicochemical information about different wine samples, such as acidity, alcohol content, density, and sulfur dioxide levels. Each sample also has a quality score assigned by experts, which will be used as the target variable for developing classification models.

Objective:

Develop a classification model capable of predicting wine quality based on its physicochemical characteristics. To simplify the problem, the quality variable should be converted into a binary classification, for example:

- High-Quality Wine: score ≥ 7
- Low/Medium-Quality Wine: score < 7

The objective is to train and evaluate machine learning models capable of predicting this classification from the available variables.

About the Dataset

Source: wine-quality-dataset

The dataset contains variables such as:

- Fixed acidity;
- Volatile acidity;
- Citric acid;
- Residual sugar;
- Chlorides;
- Free sulfur dioxide;
- Total sulfur dioxide;
- Density;
- pH;
- Sulphates;
- Alcohol;
- Wine quality (quality).

THE CHALLENGE

Develop an analysis and modeling pipeline that covers the following stages:

1. Problem Understanding
   - Interpret the problem context.
   - Clearly define the target variable.
   - Convert the quality variable into a binary classification.

2. Exploratory Data Analysis (EDA)
   - Investigate the distribution of the variables.
   - Identify correlations between variables and justify each one.
   - Detect potential outliers or inconsistent values.

Evaluate the models using appropriate metrics. A comparison among the tested models must also be conducted.
